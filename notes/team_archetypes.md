# Cobblemon Delta Ranked Team Archetypes

## Aggressive Balance
Uses 2–3 real offensive threats with 3–4 support/glue Pokémon. Example pieces: Scizor-Mega, Ogerpon-Wellspring, Delta Marshadow/Secret Armor, Tinkaton-Gamma, Gliscor/Garganacl/Shrookle, Draculedge/Tangled Time. Strength is flexibility; weakness is becoming too passive or too physical.

## Web Offense
Uses Sticky Web to let mid-speed attackers move first. Shrookle was the main Web lead. Earlier set: Sticky Web / Sludge Bomb / Spore / Toxic Spikes. Later set: Sticky Web / Rapid Spin / Leech Seed / Toxic. Weakness: top-ladder anti-lead sequencing with Mega Lopunny into Gholdengo-Delta.

## Rain Offense
Common overloaded physical rain: Pelipper / Barraskewda / Urshifu-Rapid / Ogerpon-Wellspring / Mega Swampert / Delta Typhlosion. Problem is too physical-heavy. Improved direction: Pelipper / Urshifu-Rapid / Ogerpon-Wellspring / Iron Sentinel / Delta Typhlosion / Ferrothorn. Iron Sentinel gives special rain pressure; Ferrothorn gives glue.

## Trick Room
Core idea: set TR and use slow monsters with huge offensive stats. Key candidates: Iron Coil, Golurk-Delta, Ursasola, Magigrigus, Cresselia. Use 2–3 setters and 2–3 abusers, not six slow Pokémon.

## Hyper Offense
Minimal defensive switching. Needs dedicated lead, hazards/screens, immediate threats, setup win condition, revenge killing, and anti-stall breaker. Kyurem + Valiant/Valiant Time is the next requested HO direction.

## Screens Offense
Screens give setup sweepers free turns. Grimleon/Grimmeon shifted into screen setter role after Wish was unavailable. Good partners: Ogerpon, Tangled Time, Draculedge, Secret Armor, Mega Scizor, Atom Gallade, Kyurem/Valiant threats.

## Semi-Stall / Bulky Balance
Uses durable cores like Tinkaton-Gamma, Gliscor, Corviknight, Heatran/Heatran-Delta, Clefgar, Alomomola, Ferrothorn. Needs real win conditions or it becomes passive.

## Archapult Aggressive Balance
Required Archapult, wanted aggressive style and a tank pivot. Customer disliked too many Steel and physical mons. Clefgar replaced Kingambit to add special utility, Will-O-Wisp, Poison Heal longevity, Protect scouting, and Fairy/Ghost defensive value.
